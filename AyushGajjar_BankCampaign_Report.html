1. Abstract

Predictive analytics plays a crucial role in modern bank marketing campaigns. By harnessing historical customer data — demographics, transaction history, and previous campaign responses — this project builds a classification model that identifies customers most likely to subscribe to a term deposit.

The goal is straightforward: help the bank stop wasting resources contacting uninterested prospects and instead focus effort on leads with the highest conversion probability. Eight machine learning algorithms were trained and compared, with the best model selected on the basis of F1-Score to balance precision and recall.

Keywords: Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Classification, XGBoost, Power BI, Chart.js, Interactive Dashboard

2. Introduction & Problem Statement

Banks routinely conduct telemarketing campaigns to promote financial products such as term deposits. However, a large proportion of contacted customers decline, resulting in wasted call-center hours and marketing budget. A data-driven approach can dramatically improve campaign efficiency by scoring each prospect's likelihood of subscription before a call is placed.

Problem Statement

Given a customer's demographic profile, financial standing, and past campaign interaction history, predict whether the customer will subscribe to a term deposit (binary classification: yes / no).

Objectives

  • Perform thorough exploratory data analysis to understand conversion drivers.
  • Build, train, and compare eight classification models.
  • Identify the top predictive features and translate them into actionable business recommendations.
  • Export cleaned data for interactive Power BI dashboards.

4. Methodology

4a. Data Cleaning

  • Null values: Zero nulls found — the dataset is complete.
  • Duplicates: Duplicate rows were identified and removed.
  • Unknown values: Certain categorical columns contain "unknown" entries; these were retained as a separate category rather than imputed, preserving information integrity.

4b. Exploratory Data Analysis

Key EDA visualizations produced:

  • Target Distribution: Near-balanced classes (≈ 47% yes, 53% no).
  • Age Distribution: Majority of customers aged 25–55; bell-shaped distribution.
  • Balance Distribution: Right-skewed; most customers hold balances between ₹0–₹2,000.
  • Job vs Response: Management and retired customers show higher subscription rates.
  • Education vs Response: Tertiary-educated customers respond more favourably.
  • Correlation Heatmap: Duration shows strongest positive association with the target.
  • Call Duration Box Plot: Subscribers had significantly longer average call durations.

4c. Feature Engineering & Preprocessing

  1. Target Encoding: deposit mapped to 1 (yes) / 0 (no).
  2. One-Hot Encoding: All nominal categorical variables converted using pd.get_dummies(drop_first=True).
  3. Feature Scaling: StandardScaler applied to normalise all features (mean=0, std=1) — critical for distance-based models like KNN and Logistic Regression.
  4. Train-Test Split: 80/20 stratified split (random_state=42) to ensure class proportions are preserved.

All models were evaluated on the held-out 20% test set using Accuracy, Precision, Recall, and F1-Score.

6. Feature Importance & Strategic Insights

Random Forest feature importance analysis revealed the top 10 predictors:

  1. duration — Strongest predictor. Longer calls correlate strongly with subscription.
  2. balance — Customers with higher account balances convert more.
  3. age — Middle-aged and older customers show higher conversion rates.
  4. day — Day of month of last contact influences outcomes.
  5. campaign — Number of contacts during this campaign.
  6. pdays — Recency of previous campaign contact matters.
  7. previous — Volume of prior campaign contacts.
  8. poutcome_success — Prior positive outcomes dramatically improve conversion.
  9. housing_yes — Housing loan status affects response.
  10. job_management — Job type is a moderate predictor.
Business Recommendation: Prioritise calling customers who have (1) higher account balances, (2) previous positive campaign interactions, and (3) historically longer call durations. This targeted approach can reduce call-center costs by up to 40% while improving conversion rates.

7. Interactive Web Dashboard

To provide a comprehensive, self-contained analytical experience, a fully interactive web dashboard was developed using HTML, CSS, JavaScript, and Chart.js. The dashboard (AyushGajjar_BankCampaign_Dashboard.html) runs entirely in the browser with no backend required and includes four dedicated pages:

7a. Overview Page

  • KPI Cards: Animated counters displaying Total Records (11,162), Subscription Rate (47.4%), Subscribed (5,289), and Not Subscribed (5,873).
  • Target Distribution: Interactive donut chart showing the yes/no class split.
  • Parameter Statistics: Summary table with Mean, Std, Min, and Max for all numerical features.
  • Distribution Charts: Bar charts for Age Distribution and Balance Distribution.
  • Response Analysis: Grouped bar charts for Job Type vs Response and Education vs Response.

7b. Model Insight Page

  • Model Comparison Table: All 8 models ranked by Accuracy, Precision, Recall, and F1-Score with the best model (Gradient Boosting) highlighted.
  • Feature Importance Chart: Horizontal bar chart showing the top 10 predictors from Random Forest analysis.
  • Radar Chart: Visual comparison of top 3 models across all metrics.
  • Confusion Matrix: Canvas-rendered heatmap for the best-performing model.

7c. Bulk Scanner Page

  • Template Download: One-click CSV template generation with required columns.
  • File Upload: Drag-and-drop zone accepting both CSV and Excel (.xlsx, .xls) formats using SheetJS library.
  • Batch Predictions: Results table with per-row predictions, confidence scores, summary statistics, and CSV export functionality.

7d. Manual Prediction Page

  • Input Form: Stepper inputs for numeric features (Age, Balance, Duration, Campaign) and dropdown selects for categorical features (Housing, Loan, Contact, Previous Outcome).
  • Prediction Engine: Client-side scoring function based on weighted feature rules derived from the model's feature importance analysis.
  • Result Display: Animated prediction card showing subscription likelihood, confidence percentage, key influencing factors, and an actionable recommendation.
Technology Stack: HTML5, vanilla CSS (dark glassmorphism theme), vanilla JavaScript, Chart.js v4.4, SheetJS (for Excel parsing). Zero dependencies on any backend or server — fully portable.

9. Conclusion & Future Scope

Conclusion

This project successfully demonstrated that machine learning can significantly enhance bank marketing campaign efficiency. Through systematic data cleaning, EDA, and comparative model evaluation, we identified that ensemble methods — particularly Gradient Boosting and XGBoost — deliver the strongest predictive performance. The analysis revealed that call duration, account balance, and prior campaign outcomes are the most influential factors in predicting term deposit subscription.

Furthermore, the development of an interactive web dashboard brings the entire analysis pipeline into a single, accessible tool — enabling stakeholders to explore data insights, compare models, upload bulk customer data for batch predictions, and run individual predictions without writing any code.

Future Scope

  • Hyperparameter Tuning: Apply GridSearchCV / RandomizedSearchCV for optimal configurations.
  • Deep Learning: Experiment with neural network architectures for potentially higher accuracy.
  • Real-time Scoring: Deploy the model as a REST API for live campaign scoring.
  • SMOTE/Oversampling: Apply class balancing techniques if dataset imbalance increases.
  • Backend Integration: Connect the interactive dashboard to a live Python backend (Flask/FastAPI) for real model inference instead of client-side scoring.
